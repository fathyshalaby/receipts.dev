How the agent thought

Plan

Add a single `.lp a:focus-visible, .lp button:focus-visible` rule (violet outline, offset, rounded) so links/buttons get a clear on-brand focus indicator. The landing page previously had zero focus-visible styling of its own — keyboard users fell back to whatever the browser's default (if any) rendered.

Decisions

  • Used :focus-visible rather than :focus so mouse clicks don't show the ring, only actual keyboard navigation does — avoids the classic 'ugly outline on every click' complaint while keeping it for keyboard users
  • Scoped the rule to `.lp a, .lp button` (matches every interactive element already on the page) instead of per-component rules, since the page has no custom-styled form controls needing different treatment

Rejected alternatives

  • Per-button focus styles (e.g. only .btn:focus-visible) — rejected because the six plain nav/footer links needed the same treatment and a single shared rule covers both with less duplication
